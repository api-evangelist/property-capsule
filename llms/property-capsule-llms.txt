# Property Capsule

> Property Capsule (PropertyCapsule) is a retail and commercial real estate marketing automation
> and prospecting platform for landlords and brokers. It centralizes property, tenant, space and
> availability data in one place and automatically publishes it as flyers, tourbooks, interactive
> site plans, aerials, demographics, heat maps and competition maps across web, email, PDF, print,
> touchscreen and an iPad leasing app. VTS acquired PropertyCapsule in October 2019 and the
> capabilities were folded into VTS Market.

This file is GENERATED by API Evangelist from the public Property Capsule surface. Property Capsule

## API status — read this first

- A **Developer API exists**. It was announced live on 2020-06-18 in the public release notes:
  "Our robust API is now live! Now your developers can access PropertyCapsule data outside of our
  platform... Contact our support team (support@propertycapsule.com) for more information."
- The API is **fully gated**. `https://api.propertycapsule.com` answers every path with the
  plain-text body `You must authenticate.`; `https://api.propertycapsule.com/api` exposes an Apache
  directory index listing `v1/` and `v2/`, and both require authentication. Authentication is
  session-based (a `JSESSIONID` cookie is set on every response).
- There is **no public API reference and no machine-readable contract**. No OpenAPI, Swagger,
  GraphQL SDL, AsyncAPI, Postman collection, JSON Schema or MCP server is published anywhere on
  the Property Capsule surface, and the public help center has no developer section. Access to the
  reference is obtained by contacting support.
- Do not attempt to call the API without credentials, and do not infer endpoints. Nothing about the
  request or response shape of this API is public.

## Products

- Enterprise Admin — the property/space/tenant system of record (admin.propertycapsule.com)
- Marketing Automation — flyers, tourbooks, web flyers, HTML email templates, PDF and print output
- Site Plan Editor / Interactive Site Plans — plans that update themselves as tenancy changes
- Map Maker / Capsule Maps — demographics, competition aerials, lease-expiration heat maps
- Tourbooks (tours.propertycapsule.com)
- Retail Marketplace / Maps embed app (maps.propertycapsule.com)
- iPad leasing app (iOS)
- Data feeds — outbound nightly feeds with per-run change logs mailed to configured recipients

## Documented integration surface (marketing claims, not a reference)

From https://propertycapsule.com/details, under "Live Data APIs":
- "REST, JSON, JSONP, XML and widgets"
- Custom integrations into internal systems and websites
- Custom Salesforce and Microsoft Dynamics CRM integration
- Two-way enterprise integrations, including nightly PDF drops to a shared drive and listing
  upload into other systems
- Data feeds to and from JD Edwards, Oracle, MRI and Yardi

These are claims on a marketing page. No endpoint, parameter, schema or auth detail accompanies them.
